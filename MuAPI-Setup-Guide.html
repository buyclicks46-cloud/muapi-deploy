1. Overview

The MuAPI MCP Server connects Claude Desktop to MuAPI's suite of 25+ AI tools — including image generation, video creation, audio processing, media enhancement, and more — directly inside your Claude conversations.

This package includes a compatibility proxy that ensures seamless communication between the MuAPI server and the latest version of Claude Desktop, handling protocol differences automatically.

3. Quick Setup (Automated)

The fastest way to get started. The setup script automatically detects your OS, locates Claude Desktop, installs the proxy, and verifies the connection.

1
Download the deployment package

Save the muapi-deploy folder to any location on your computer.

2
Close Claude Desktop completely

Right-click the Claude icon in the system tray and select "Quit." Ensure no Claude processes are running.

3
Open a terminal in the muapi-deploy folder and run: 
node setup-muapi.js --api-key YOUR_API_KEY_HERE

Replace YOUR_API_KEY_HERE with your actual MuAPI API key.

4
Wait for all 4 tests to pass

The setup will display test results. All 4 tests should show ✅.

5
Start Claude Desktop and open a new chat

Your MuAPI tools are now active! Ask Claude to use any MuAPI tool.

✅ Expected Output You should see: "Results: 4/4 tests passed — All tests passed! MuAPI MCP server is working correctly."

4. Manual Setup

If you prefer to set things up manually or the automated installer doesn't work for your environment:

Step 1: Copy proxy-mcp.js

Copy the proxy-mcp.js file to your Claude Desktop configuration directory:

Operating SystemConfig Directory
Windows (Store)%LOCALAPPDATA%\Packages\Claude_*\LocalCache\Roaming\Claude\
Windows (Direct)%APPDATA%\Claude\
macOS~/Library/Application Support/Claude/
Linux~/.config/Claude/

Step 2: Edit claude_desktop_config.json

Open (or create) the file claude_desktop_config.json in the same directory and add the muapi entry:

{
  "mcpServers": {
    "muapi": {
      "command": "node",
      "args": [
        "C:\\full\\path\\to\\proxy-mcp.js"
      ],
      "env": {
        "MUAPI_API_KEY": "your-api-key-here"
      }
    }
  }
}
⚠️ Important Use the full absolute path to proxy-mcp.js. On Windows, use double backslashes \\ in the JSON. Keep any existing entries in mcpServers — just add the "muapi" block alongside them.

Step 3: Restart Claude Desktop

Fully close and reopen Claude Desktop. The MuAPI tools will be available in all new chats.

7. Troubleshooting

❌ Claude says "I don't have access to that tool"

  • Solution: Start a new chat. Tools aren't retroactively added to old chats.
  • If it persists, fully restart Claude Desktop (quit from system tray, not just close window).
  • Run node setup-muapi.js --test-only to verify the connection.

❌ Setup says "npx not found"

  • Solution: Install Node.js from nodejs.org and restart your terminal.

❌ Setup tests fail

  • Check your internet connection (muapi-cli needs to be downloaded on first run).
  • Verify your API key is correct at muapi.ai.
  • On Windows, if you see execution policy errors, run npx.cmd instead of npx.

❌ Config file keeps getting overwritten

  • Solution: Always fully close Claude Desktop before editing the config file. Claude overwrites the file on shutdown.

8. Uninstall

To remove MuAPI from Claude Desktop:

node setup-muapi.js --uninstall

This will remove the muapi entry from your config and delete the proxy script. Restart Claude Desktop after uninstalling.
